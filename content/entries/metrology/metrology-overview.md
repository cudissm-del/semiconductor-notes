> 공정 단계마다 무엇을 어떤 계측으로 재는지, 3D 시대에 계측이 왜 어려워지는지의 총론.

공정 결과는 측정으로만 확인할 수 있다. 계측은 크게 **라인 안에서 빠르게 매번 보는 인라인 계측**과, **웨이퍼를 잘라 깊이 보는 오프라인 분석**으로 나뉜다. 인라인은 공정 제어에, 오프라인은 원인 분석과 신공정 개발에 쓴다.

### 무엇을 무엇으로 재나

| 측정 대상 | 장비 / 기법 | 인라인 여부 | 특징 |
| --- | --- | --- | --- |
| 선폭(CD), 선 거칠기(LER·LWR) | CD-SEM | 인라인 | 위에서 본 이미지, 비파괴, 3D 형상엔 한계 |
| 3D 프로파일 (높이, 측벽각, 리세스 깊이) | OCD (광학 산란계측) | 인라인 | 반사 스펙트럼을 모델과 맞춰 형상 추출, 빠름, 모델 의존 |
| 오버레이 | 이미지 기반(IBO)·회절 기반(DBO) 계측 | 인라인 | 층간 정렬 오차, nm 이하 요구 |
| 막 두께, 굴절률 | 엘립소메트리, 반사율 측정 | 인라인 | 박막 표준 측정 |
| 두께·밀도·조성 | XRR, XRF | 인라인 / 오프라인 | 초박막, 금속막 |
| 표면 형상·거칠기 | AFM | 오프라인 위주 | CMP 디싱, ALE 표면 거칠기 |
| 단면 구조 (원자 수준) | TEM / STEM + EDS·EELS | 오프라인 (파괴) | GAA 시트·내부 스페이서·HKMG 두께 확인의 최종 수단, FIB로 시편 제작 |
| 표면 화학 결합 상태 | XPS | 오프라인 | 표면 수 nm의 원소·결합 상태, 스퍼터·각도 분해로 깊이 정보 |
| 막 속 화학 결합 | FTIR | 오프라인 / 일부 인라인 | low-k의 Si–CH₃, Si–OH 변화 |
| 도펀트 깊이 분포 | SIMS | 오프라인 | ppm 수준 감도, 이온주입·확산 확인 |
| 면저항 | 4탐침 | 인라인 | 금속·실리사이드·도핑층 |
| 결함 | 명시야·암시야 광학 검사, 전자빔 검사 → 리뷰 SEM | 인라인 | 입자·패턴 결함을 찾고 분류 |
| 전기 특성 | WAT(웨이퍼 수용 테스트), EDS | 인라인 끝 / 후공정 | 소자 파라미터, 최종 수율 |

### 3D 시대의 계측 과제

- GAA, 3D NAND처럼 **보이지 않는 내부 구조**(시트 사이 리세스 깊이, 채널홀 바닥 CD)는 위에서 보는 CD-SEM으로 잴 수 없다. OCD 모델, X선 기반 계측, 샘플링 TEM을 조합한다.
- 측정값 여러 개를 함께 써서 정확도를 높이는 **하이브리드 계측**, 장비 센서 데이터로 결과를 예측하는 **가상 계측**이 확대되고 있다.
- 플라즈마 식각 연구에서는 **OES**(플라즈마 발광)로 공정 중 상태를, **XPS·FTIR**로 공정 후 표면 화학을 보는 조합이 표준적이다.
