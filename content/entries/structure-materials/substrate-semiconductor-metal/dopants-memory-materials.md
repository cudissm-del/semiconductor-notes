> 전기적 성질을 정하는 도펀트와, 메모리 소자 전용 물질 (강유전체·상변화·자성 재료 등).

### 도펀트와 메모리 전용 물질

**도펀트·주입 원소** — 이온주입이나 in-situ 에피 도핑으로 Si의 전기적 성질을 바꾼다.

| 원소 | 역할 | 쓰이는 곳 |
| --- | --- | --- |
| B (붕소), BF₂ | p형 도펀트 — PMOS S/D, n-well 내 p+ 영역, Vt 조절 | FEOL |
| P (인) | n형 도펀트 — NMOS S/D, n-well, 도핑 poly | FEOL |
| As (비소) | n형 도펀트 — 무거워 얕은 접합(LDD, S/D 확장)에 유리 | FEOL |
| In, Sb | 무거운 p형/n형 — halo, 채널 도핑 일부 | FEOL |
| C, F, N | 확산 억제(C), 결함 패시베이션(F), 계면 질화(N) | FEOL |
| Ge, Si (PAI) | 사전 비정질화 주입 — 채널링 방지, 얕은 접합 | FEOL |
| H (수소) | 계면 결함(dangling bond) 패시베이션 — 포밍가스 어닐 | 공정 말미 |

**메모리 전용 물질**

| 물질 | 역할 | 소자 |
| --- | --- | --- |
| SiO₂/Si₃N₄/SiO₂ (ONO) | 터널 산화막 / 전하 트랩층(SiN) / 블로킹 산화막 | 3D NAND (CTF 셀) |
| Al₂O₃, HfO₂ 블로킹층 | 블로킹 유전체의 고유전 보강 | 3D NAND |
| SiO₂/Si₃N₄ 교대 적층 (수백 층) | 셀 스택 몰드 (나중에 SiN을 W 워드라인으로 치환) | 3D NAND |
| ZrO₂, HfO₂, Al₂O₃ 적층 | 커패시터 유전체 (고유전 + 누설 억제) | DRAM |
| TiN | 커패시터 상·하부 전극 | DRAM |
| HZO (Hf₀.₅Zr₀.₅O₂) | 강유전체 — 분극으로 데이터 저장 | FeRAM, FeFET (연구·초기 양산) |
| GST (Ge₂Sb₂Te₅) | 상변화 물질 | PCM |
| CoFeB / MgO | 자기 터널 접합 | MRAM |

### 도펀트 — 넣는 양과 활성화가 따로 논다

도펀트 공정에서 정해야 하는 것은 원소만이 아니다. **농도, 깊이(접합 프로파일), 활성화 비율** 세 가지가 따로 움직인다.

- **농도 창** — 채널·Vt 조절은 대략 10¹⁶~10¹⁸ cm⁻³, S/D 고농도 영역은 10²⁰ cm⁻³ 안팎까지 올라간다 (교재 전형 범위). 고상 용해도를 넘겨 넣으면 석출·클러스터로 비활성화돼, 넣은 양만큼 전기적으로 일하지 않는다.
- **깊이** — As처럼 무거운 원소는 얕게 멈춰 얕은 접합에 유리하고, B처럼 가벼운 원소는 깊이·채널링을 관리해야 한다. 그래서 B는 BF₂ 분자 주입이나 사전 비정질화(PAI)와 함께 쓰는 경우가 많다.
- **확산** — 주입 뒤 어닐에서 도펀트가 움직이면 설계한 접합이 번진다. C 공동 주입으로 B 확산을 억제하는 식의 "도펀트끼리의 간섭"도 설계 변수다 ([[어닐과 확산]]).

활성화 어닐은 손상 회복·활성화와 확산 억제 사이의 줄다리기다. 온도를 올리면 활성화는 좋아지지만 프로파일이 번지므로, 최신 노드는 짧고 뜨거운 스파이크·레이저 어닐로 시간을 줄이는 방향으로 갔다.

### 메모리 물질 — 저장 원리가 곧 재료 조건

| 저장 원리 | 상태를 무엇으로 나누나 | 재료에 걸리는 조건 |
| --- | --- | --- |
| 전하 저장 (NAND) | 트랩층에 잡힌 전하량 | 트랩 밀도, 리텐션(누설 차단), 반복 기록에 따른 막 열화 |
| 커패시터 (DRAM) | 유전체 양단의 전하 | 높은 k와 낮은 누설을 동시에 — 박막화하면 누설이 먼저 샌다 |
| 강유전체 (FeRAM·FeFET) | 자발분극의 방향 | HZO의 강유전 상(orthorhombic) 안정화, 피로·임프린트, 웨이크업 거동 |
| 상변화 (PCM) | 비정질/결정질 저항 차이 | GST의 빠른 결정화와 비정질 안정성 사이의 절충, 반복 스위칭 내구성 |
| 자성 (MRAM) | 자유층 자화 방향 | MgO 터널 배리어의 균일도, CoFeB 계면 수직자기이방성 유지 |

공통점은 셀이 작아질수록 **부피가 아니라 계면과 상(phase)이 성능을 정한다**는 것이다. HZO는 조성(Hf:Zr ≈ 1:1)뿐 아니라 두께·전극 응력·어닐로 강유전 상을 잡아야 하고, DRAM 유전체는 ZrO₂/Al₂O₃ 적층처럼 "k가 큰 층"과 "누설을 막는 층"을 나눠 쌓는 식으로 절충한다.

### 한계·이슈

- **랜덤 도펀트 변동 (RDF)** — 채널 부피가 작아지면 도펀트 원자 수 자체가 수십~수백 개 수준이 돼, 개수와 위치의 통계적 흔들림이 Vt 산포가 된다. 미세 소자에서 채널 무도핑 설계가 선호되는 배경이다.
- **메모리 재료의 신뢰성** — 저장 원리가 원자 재배열(상변화·분극 반전)에 기대는 재료는 반복 동작에서 피로가 쌓인다. 용량·속도보다 내구성과 리텐션이 양산의 문턱인 경우가 많다.
- **공정 오염** — 도펀트와 금속 불순물은 의도한 자리 밖에서는 수명을 깎는 오염원이다. 메모리 물질 전용 장비·교차오염 관리가 별도 라인 규율이 된다.

## 근거

- 도펀트 농도 범위는 공정 교재의 전형 구간이며, 소자·노드별 설계값이 아니다.
- 메모리 물질의 역할 구분은 기존 표의 소자 대응을 기준으로 정리했고, 특정 논문의 실측 수치는 새로 넣지 않았다.
