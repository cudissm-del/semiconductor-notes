> 칩을 보호하고 외부와 잇는 패키징 소재들 — 몰딩 컴파운드, 언더필, 기판 재료 등.

### 패키징 소재

후공정 소재는 전기 연결과 함께 열팽창 차이(CTE mismatch)로 인한 휨과 균열을 견디는 것이 핵심이다.

| 물질 | 역할 | 쓰이는 곳 |
| --- | --- | --- |
| Au, Cu, Ag 와이어 | 칩 패드 ↔ 기판 연결 | 와이어 본딩 |
| SnAg 등 무연 솔더 | 범프, BGA 솔더볼 | 플립칩, 기판 실장 |
| Cu 필러 + 솔더 캡 | 미세 피치 범프 | 플립칩, 마이크로범프(HBM 등) |
| UBM (Ti/Cu, Ni/Au 등) | 패드와 범프 사이 접착·확산 방지층 | 범핑 |
| Cu (하이브리드 본딩 패드) + SiO₂/SiCN 본딩 유전체 | 범프 없는 Cu–Cu / 유전체–유전체 직접 접합 | 하이브리드 본딩 |
| Cu (TSV) + SiO₂ 라이너 | 실리콘 관통 전극 | 3D 적층, 인터포저 |
| 폴리이미드, PBO | RDL 층간 절연, 응력 완충, 칩 보호막 | WLP, 범핑 |
| 언더필 (에폭시 + 실리카 필러) | 범프 주변을 채워 열응력 분산 | 플립칩 |
| NCF / MUF | 범프 사이 비전도 접착 필름, 몰딩과 언더필 겸용 | HBM 적층 |
| EMC (에폭시 몰딩 컴파운드) | 칩 봉지·보호 | 몰딩 |
| DAF (다이 접착 필름) | 다이를 기판·다이 위에 고정 | 다이 어태치, 적층 |
| 유기 기판 (BT, ABF 빌드업) | 칩과 PCB 사이 배선 기판 | FC-BGA 등 |
| Si 인터포저 / 유리 기판 | 칩 간 초미세 배선 플랫폼 | 2.5D (유리는 차세대) |
| TIM (열계면 물질) | 칩과 히트스프레더 사이 열 전달 | 고성능 패키지 |
