전기적 성질을 정하는 도펀트와, 메모리 소자 전용 물질 (강유전체·상변화·자성 재료 등).

도펀트와 메모리 전용 물질

도펀트·주입 원소 — 이온주입이나 in-situ 에피 도핑으로 Si의 전기적 성질을 바꾼다.

원소 역할 쓰이는 곳
B (붕소), BF₂ p형 도펀트 — PMOS S/D, n-well 내 p+ 영역, Vt 조절 FEOL
P (인) n형 도펀트 — NMOS S/D, n-well, 도핑 poly FEOL
As (비소) n형 도펀트 — 무거워 얕은 접합(LDD, S/D 확장)에 유리 FEOL
In, Sb 무거운 p형/n형 — halo, 채널 도핑 일부 FEOL
C, F, N 확산 억제(C), 결함 패시베이션(F), 계면 질화(N) FEOL
Ge, Si (PAI) 사전 비정질화 주입 — 채널링 방지, 얕은 접합 FEOL
H (수소) 계면 결함(dangling bond) 패시베이션 — 포밍가스 어닐 공정 말미

메모리 전용 물질

물질 역할 소자
SiO₂/Si₃N₄/SiO₂ (ONO) 터널 산화막 / 전하 트랩층(SiN) / 블로킹 산화막 3D NAND (CTF 셀)
Al₂O₃, HfO₂ 블로킹층 블로킹 유전체의 고유전 보강 3D NAND
SiO₂/Si₃N₄ 교대 적층 (수백 층) 셀 스택 몰드 (나중에 SiN을 W 워드라인으로 치환) 3D NAND
ZrO₂, HfO₂, Al₂O₃ 적층 커패시터 유전체 (고유전 + 누설 억제) DRAM
TiN 커패시터 상·하부 전극 DRAM
HZO (Hf₀.₅Zr₀.₅O₂) 강유전체 — 분극으로 데이터 저장 FeRAM, FeFET (연구·초기 양산)
GST (Ge₂Sb₂Te₅) 상변화 물질 PCM
CoFeB / MgO 자기 터널 접합 MRAM
